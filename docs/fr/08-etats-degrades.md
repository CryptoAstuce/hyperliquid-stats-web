# Etats degrades

Une panne partielle ne doit pas produire un tableau visuellement complet avec des zeros inventes.
L interface distingue stale, partial, unavailable et empty avec des messages differents.
La derniere valeur valide peut rester visible si son age et l echec du rafraichissement sont affiches.
Les requetes concurrentes portent un identifiant ou signal d annulation pour rejeter une reponse tardive.
Un changement de compte, marche ou fenetre invalide les resultats de la selection precedente.
Les erreurs de parsing sont separees des erreurs HTTP afin de detecter une derive de schema.
Ces etats ameliorent la confiance sans pretendre transformer l interface en oracle.

Périmètre : lecture documentaire ; aucun appel API, build ou test n a été exécuté.
